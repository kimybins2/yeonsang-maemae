# 연상매매

국장은 예측할 수 없으니, 아무 말 연상으로 엉뚱한 종목을 추천하고
"그때 샀더라면" 실제 수익률까지 계산해 주는 개그 웹사이트입니다.

- 하림 → 닭 → 새벽 꼬끼오 → 수면 부족 → 아메리카노 → **커피 관련주(동서)**
- 실제 주가(현재가, 전일 대비, 1년 차트)는 서버가 네이버 금융에서 가져옵니다.
- 1년·3년·5년 전에 정석 종목 / 연상 종목 / 코스피를 샀다면 지금 얼마인지 비교합니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 전체 (디자인, 단골 재료 연상, 수익률 계산) |
| `assoc.js` | 연상 지도 (단어 120여 개와 그 연결, 끝점 업종과 대표 종목) |
| `api/stock.js` | 서버 함수. `/api/stock?q=하림` 으로 부르면 시세를 JSON으로 돌려줌 |
| `package.json` | 프로젝트 정보 |
| `test/` | 서버 함수와 연상 지도 테스트 (가짜 데이터) |

## 인터넷에 올리기 (무료, 약 20분)

Vercel이라는 무료 호스팅을 씁니다. 코딩이나 설치는 필요 없어요.

### 1. GitHub에 파일 올리기
1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository** 를 누릅니다.
3. Repository name에 `yeonsang-maemae` 를 쓰고, **Public** 그대로 두고 **Create repository** 를 누릅니다.
4. 다음 화면에서 **uploading an existing file** 링크를 누릅니다.
5. 압축을 푼 `yeonsang` 폴더 **안의 내용물**(`index.html`, `api` 폴더, `package.json` 등)을 한꺼번에 끌어다 놓습니다.
   `api` 폴더가 폴더째로 올라가야 합니다.
6. 아래 **Commit changes** 를 누릅니다.

### 2. Vercel에 연결하기
1. https://vercel.com 에서 **Sign Up** → **Continue with GitHub** 로 가입합니다(Hobby 무료 플랜).
2. **Add New… → Project** 를 누르고, 방금 만든 `yeonsang-maemae` 옆의 **Import** 를 누릅니다.
3. 설정은 건드리지 말고 **Deploy** 를 누릅니다.
4. 1분 정도 지나면 `https://yeonsang-maemae-xxxx.vercel.app` 같은 주소가 생깁니다. 이 링크를 공유하면 누구나 씁니다.

### 3. 잘 되는지 확인
- 주소 뒤에 `/api/stock?q=하림` 을 붙여 열어 보세요. 숫자가 잔뜩 나오면 서버가 정상입니다.
- 첫 화면의 "실제 시세" 칸에 하림과 동서 주가가 나오면 끝.

### 나중에 고치고 싶을 때
GitHub 저장소에서 파일을 수정(연필 아이콘)하거나 새 파일을 올리면 Vercel이 1분 안에 자동으로 다시 배포합니다.

## 연상 추가하는 법

### 연상 지도에 단어 추가 (`assoc.js`)
입력 문장 속에서 지도에 있는 단어(별칭)를 찾아 거기서 출발하고, 3~5단계를 건너 끝점(업종)에 도착합니다.
같은 입력은 항상 같은 결과가 나오고, "다른 연상으로 다시"를 누르면 다른 길로 갑니다.

```js
"우산": {a:["우산","양산"], e:[["비","우산은 비 올 때"],["편의점","급하게 편의점에서 삼"]]},
```
- `a`: 입력에서 찾을 단어들
- `e`: 다음 단어와 넘어가는 이유 (이유는 20자 이내)
- 끝점이 되려면 `t:["업종 관련주",["대표 종목", ...]]` 를 추가
- 새 단어를 만들었으면 다른 단어의 `e` 에서도 이어 줘야 길이 생깁니다.

### 단골 재료 추가 (`index.html` 의 `PRESETS`)
직접 손으로 쓴 연상 사슬이고, 단골 재료 버튼으로도 나옵니다.

### 종목 코드
추천 종목이 처음 보는 회사면 서버가 네이버 검색으로 코드를 찾아요.
자주 쓰는 종목은 `api/stock.js` 의 `KNOWN` 에 `이름:코드` 로 적어 두면 더 빠릅니다.
코드를 잘못 적어도 서버가 네이버 차트의 실제 회사 이름과 비교해서 다시 찾습니다.

## 알아둘 점
- 시세는 네이버 금융의 공개 데이터를 서버가 대신 읽어 오는 방식이라, 네이버가 형식을 바꾸면 고쳐야 할 수 있어요.
  같은 종목은 10분간 저장해 두고 재사용해서 요청을 줄였습니다.
- 수익률은 매달 첫 거래일 종가에 사서 지금까지 들고 있었다고 가정한 단순 계산입니다(배당·수수료·세금 제외).
- 투자 권유가 아닌 농담 사이트입니다.

## 내 컴퓨터에서 테스트 (선택)
Node.js 18 이상이 있으면 `npm test` 로 서버 함수 테스트를 돌릴 수 있습니다.
